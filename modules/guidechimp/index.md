# GuideChimp

> **Planned integration**
>
> This page describes the intended platform integration only; no Labs64.IO GuideChimp deployment or API is available yet.

GuideChimp will add contextual, in-product guidance that helps users complete unfamiliar workflows. The intended integration treats guidance as an experience layer: it can respond to product state and user context without owning the core business workflow.

| Capability | Intended behavior |
|---|---|
| Guided tours | Step-by-step prompts tied to product screens and goals |
| Contextual guidance | Show assistance based on role, tenant, or application state |
| Progressive onboarding | Help users discover advanced workflows when they are relevant |
| Outcome measurement | Observe completion and adoption signals without replacing product analytics |

When designing ahead, make each tour optional, keep business actions in the host application, and avoid putting sensitive information in guide content.
