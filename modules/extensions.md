# Extensions

Extensions provide customer-facing experiences and supporting capabilities around the core platform and commerce flow.

| Service | Role | Availability |
|---|---|---|
| [Notifications](./notifications/index.md) | Delivers transactional and operational messages | Planned |
| [Reporting](./reporting/index.md) | Turns service data into governed reports and analytics | Planned |
| [Customer Portal](./customer-portal/index.md) | Gives customers a self-service web experience | Available |
| [GuideChimp](./guidechimp/index.md) | Adds contextual product guidance and onboarding | Planned |

Adopt extensions independently where possible; use the gateway and shared tenant context when an extension accesses platform APIs.
