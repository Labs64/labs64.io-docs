# Labs64.IO Reference

Reference pages cover OpenAPI contracts, event envelope and known event types, shared configuration and environment variables, Docker images, Helm value conventions, and a glossary. APIs are OpenAPI-first. Events are AuditFlow audit events with an envelope of eventId, eventTime, timestamp, eventType, sourceSystem, tenantId, correlationId and an open `extra` map. See /docs/reference/ for authoritative links.
