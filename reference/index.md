# Reference

The Reference section contains ecosystem-wide specifications, schemas, and configuration variables.

While each module's documentation page (e.g., [AuditFlow](../modules/auditflow/)) provides specific details for that module, this section serves as a centralized lookup for:

- **[OpenAPI](./openapi.html)**: Aggregated API contracts.
- **[Events](./events.html)**: RabbitMQ event schemas and routing keys.
- **[Configuration](./configuration.html)**: Shared ecosystem configuration.
- **[Docker Images](./docker-images.html)**: Tags, base images, and user IDs.
- **[Helm Values](./helm-values.html)**: Shared chart configurations.
- **[Environment Variables](./environment-variables.html)**: Cross-module environment variables.
